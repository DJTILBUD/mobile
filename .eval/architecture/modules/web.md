# Module: web

Provides the web entrypoint HTML document for running and hosting the Flutter-based dj_tilbud_app in web browsers.

## Key files
- `web/index.html`: Entrypoint HTML document that configures web application metadata, icons, manifest links, and bootstraps the Flutter application via flutter_bootstrap.js.

## Public interface
- HTML web entrypoint loading flutter_bootstrap.js

## Dependencies
- flutter_bootstrap.js
- manifest.json
- favicon.png
- icons/Icon-192.png
