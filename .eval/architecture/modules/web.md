# Module: web

Acts as the web host shell and HTML entry point for the Flutter web build of the dj_tilbud_app client.

## Key files
- `web/index.html`: Entry HTML template that configures page metadata, app icons, web manifest, base href, and loads the Flutter bootstrap script.
